## 🔧 Installation & Setup

1. Clone the repository:
   ```bash

   ```
2. Navigate into the project directory:
   ```bash
   cd Trillo-web
   ```
3. Open the `index.html` file in your browser or run a local server:
   ```bash
   live-server
   ```
